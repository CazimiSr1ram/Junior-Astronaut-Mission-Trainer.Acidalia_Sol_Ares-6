# Mars Racer model credits

## `mars-racer-omega-ultimate.glb`

- **Origin:** procedurally reconstructed from a Blender Python design supplied by
  the project's second co-developer, and generated with AI assistance.
- **Use in the game:** a stationary exhibit on the Mars surface
  (`static/js/mars-racer-exhibit.js`). It cannot be driven.
- **Ownership:** this is an original project model. It is not a NASA model and
  is not endorsed by NASA.
- **Redistribution licence:** **pending confirmation from the contributor.**
  Until the contributor confirms the licence, do not reuse or redistribute the
  model outside this project.

## `mars-rover.glb`

The science rover is a separate model and is not covered by this file.
