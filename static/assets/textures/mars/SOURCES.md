# Mars monitor texture

`nasa-viking-mars.jpg` is the unmodified JPEG from [NASA's Mars Image Texture](https://science.nasa.gov/3d-resources/mars/), derived from Viking images processed by USGS. Credit: NASA/Jet Propulsion Laboratory & Caltech. The original file is available from [NASA Science](https://assets.science.nasa.gov/content/dam/science/cds/3d/resources/image/mars/Mars.jpg).

NASA's [image and media guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/) describe permitted educational and informational use, require acknowledgment, and prohibit implying NASA endorsement. The image is a historical global mosaic, not live imagery.
